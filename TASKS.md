- One row per unit of work. Open work lives in the active sections; finished work moves to "Completed work".
- Status values: `pending`, `in progress`, `blocked`, `done` (with evidence), `won't do` or `won't fix` (with the reason).
- `Picked up by` names a concrete session, subagent or tracked task; `Unassigned` means free to pick up. List handoffs with an arrow.
- Evidence is a PR link, test result or a short live-verification note. Keep long logs in the PR, not here.
- Never record environment data (host names, IP addresses, registries, node names, paths) or real media titles in a row.
- Add or change rows with `tasks.d/<row-number>.md` fragments; the merge train folds them in.
