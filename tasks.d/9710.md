| 9710 | Android (TV and phone): the profile chip opens the profile switcher with the account's profiles instead of an empty "Who's watching?" | done: merged (#356) | android-profile-ci worker | Owner-approved on 9 Oct 2026 despite the native parity hold. A QR-linked session stores its tokens first and learns its user id from a best-effort profile lookup afterwards; when that lookup was lost the session had a token but no identity, so the switcher listed nobody and offered only "Sign in". Release 0.3.0 has no later recovery, so the chip showed "Viewer" and the switcher was empty (reproduced on the TV emulator). Main recovers at start-up (PR 133), but a failed lookup there left the same state. The switcher now adopts the server's current profile before it lists (`adoptServerIdentityIfMissing`, `PlayarrProfileNameTest`). Fire TV and Roku findings are in the PR description. |
