Playarr is a client for a Playarr Server that each user runs themselves. It has no content of its own, and the Playarr project does not provide, host or operate servers for users or reviewers. There is no demonstration server and no review account.

On first launch the app asks for the address of the user's own server (Add server). Without a server the app stops at that screen by design. On Apple TV, sign-in uses an on-screen short code that the user approves from a browser on their own server.

When a server is reachable, the app plays its library with the native player. Downloads, profiles and Chromecast are optional and need no extra setup.

Local network access is requested only to find a server and Chromecast devices on the user's own network.
