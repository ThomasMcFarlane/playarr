# -- Why the keep list below exists -------------------------------------------
# Every name listed under -keep-property-name is a JSON field name that is
# part of the Playarr wire contract (server request/response bodies decoded
# or encoded in core/Types/*.ts, core/Jwt.ts, core/ErrorEnvelope.ts,
# core/DeviceCodePolicy.ts, data/*Repository.ets and player/*.ets — see brief
# §4). These names are read with plain property access against parsed JSON,
# never through a name-preserving reflection layer, so ArkGuard's property
# obfuscation pass cannot tell they are wire-visible and would otherwise
# rename them — silently breaking every request/response the moment a release
# build ships. They must stay exactly as the server sends/expects them.
#
# This list is deliberately over-inclusive: keeping a name that obfuscation
# would not otherwise have touched costs nothing, whereas missing one is a
# runtime-only failure this offline validator cannot catch (see brief §7.4).
